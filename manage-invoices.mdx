# Manage Invoices

Once invoices are uploaded, they can be reviewed, filtered, viewed, and deleted when needed.

## Admin capabilities

- Search by invoice number
- Filter by category, member, and date range
- Switch between grid and list views
- Download multiple invoices at once
- Open invoice details in a modal

## User capabilities

- View only the invoices they uploaded
- Review uploaded invoice details
- Remove their own invoices if needed
