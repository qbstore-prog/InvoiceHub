# Visão técnica

O Expensar foi desenvolvido com uma stack web moderna:

- Next.js para o aplicativo web
- NextAuth para autenticação
- Prisma e PostgreSQL para modelagem de dados
- AWS S3 para armazenamento seguro de arquivos de faturas
- Tailwind CSS para uma interface responsiva
